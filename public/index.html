HOW MILEMARK WORKS Express Architecture

1. Express Middleware: Incoming requests are parsed with express.json() and served from the public folder.

2. RESTful Services:
• GET /api/vehicles - Read fleet
• POST /api/vehicles - Create vehicle
• POST /api/rent/:id - Rent vehicle
• PUT /api/return/:id - Return vehicle
• DELETE /api/vehicles/:id - Delete vehicle

3. MongoDB: Vehicle and rental information is stored permanently in MongoDB.
